## Recent projects

### [Motif](https://motif-productivity-suite.vercel.app/): a local-first productivity app

Motif puts tasks, projects, focus sessions, and analytics in one workspace. You don't need an account or subscription, and it sends no usage analytics. Your data stays in the browser unless you export it.

You can switch between a list, a board with work-in-progress (WIP) limits, an Eisenhower matrix, and a seven-day schedule. A quick note like `draft proposal in 3 days #work !high ~1h` fills in the due date, project, priority, and time estimate.

I added no-code automations, `.ics` calendar export, and readable JSON import/export. Contrast checks run in the build, so a design-token change that lowers contrast fails before it ships.

### [Bagged Up](https://baggedup-seven.vercel.app): a storefront for a Kenyan boutique

Bagged Up is a 50-item online shop I built for a Kenyan boutique. I handed it over to the owner in October 2026.

Customers choose M-Pesa or cash on delivery, then use WhatsApp to confirm stock and delivery with the owner. Delivery is KSh 250 in Nairobi and KSh 400 countrywide. Orders over KSh 5,000 ship free. The site shows the expected arrival date before checkout.

It's a static site on an edge CDN, with no framework, bundler, or runtime dependencies. I also wrote handover notes for the owner.
